🐱🐶 Cats vs Dogs Image Classification

📌 Overview

This project explores the application of Artificial Neural Networks (ANNs) and Convolutional Neural Networks (CNNs) for the classification of cat and dog images. The goal is to build and compare models that can automatically distinguish between images of cats and dogs, showcasing the power of deep learning in solving image recognition problems.

🎯 Objectives

Preprocess and prepare an image dataset for deep learning

Build and evaluate ANN and CNN models for binary image classification

Compare model performance and highlight the advantages of CNN in image-based tasks

Visualize training metrics and prediction results

🧠 Techniques & Tools

Python with libraries: TensorFlow, Keras, NumPy, Matplotlib, Pandas

Data Preprocessing: image resizing, normalization, data augmentation

Modeling:

ANN for baseline performance

CNN for feature extraction and improved accuracy

Evaluation Metrics: Accuracy, Loss, Confusion Matrix

Visualization: Training curves and sample predictions
