# Cats vs Dogs Image Classification

> A deep learning project comparing ANN and CNN architectures for binary image classification — distinguishing cats from dogs — with full preprocessing, training, and evaluation pipelines.

**Status:** 🌐 Public repository

## Overview

Explores how far a basic Artificial Neural Network can go on an image classification task versus a Convolutional Neural Network purpose-built for it — using the classic cats-vs-dogs problem as the testbed. Both models are built, trained, and evaluated side by side to make the performance gap concrete rather than theoretical.

## Objectives

- Preprocess and prepare an image dataset for deep learning
- Build and evaluate both ANN and CNN models for binary image classification
- Compare model performance and highlight CNNs' advantage on image-based tasks
- Visualize training metrics and prediction results

## Techniques & Tools

- **Language/Libraries:** Python, TensorFlow, Keras, NumPy, Matplotlib, Pandas
- **Data preprocessing:** image resizing, normalization, data augmentation
- **Modeling:** ANN baseline model, CNN for feature extraction and improved accuracy
- **Evaluation:** accuracy, loss, confusion matrix
- **Visualization:** training curves and sample predictions

## Use Case Example

A useful reference project for anyone learning the practical difference between dense (ANN) and convolutional (CNN) architectures on real image data — the side-by-side comparison makes the accuracy/loss gap and CNN's spatial feature advantage directly visible rather than something you just have to take on faith.
